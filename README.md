# เบอร์มงคล

เว็บไซต์ภาษาไทยสำหรับเรียนรู้แนวคิดเลขศาสตร์และทดลองเครื่องมือคำนวณเบื้องต้น สร้างด้วย HTML, CSS และ JavaScript ล้วน ใช้ GitHub Pages ได้ฟรีโดยไม่จำเป็นต้องซื้อโดเมน

## ไฟล์เว็บไซต์
- `index.html` — หน้าแรก เครื่องมือเบอร์โทร/วันเกิด และลิงก์ไปยังคู่มือเฉพาะหัวข้อ
- `phone-number.html` — คู่มือทำนายเบอร์โทรศัพท์
- `lucky-number-pairs.html` — ความหมายคู่เลขเบอร์โทรศัพท์
- `birth-date-numbers.html` — วิธีคำนวณเลขวันเกิด
- `phone-number-sum.html` — วิธีคำนวณผลรวมเบอร์โทรศัพท์
- `unlucky-numbers-by-birthday.html` — แนวคิดเลขกาลกิณีตามวันเกิด
- `robots.txt` — กติกาพื้นฐานสำหรับ crawler

## อัปโหลดจาก iPhone
ไฟล์ HTML ทุกหน้าอยู่ใน root เดียวกัน ไม่ต้องสร้างโฟลเดอร์ย่อย: แตก ZIP แล้วอัปโหลดไฟล์ HTML ทั้ง 6 ไฟล์และ `robots.txt` ไปยัง root ของ GitHub repository จากนั้นกด **Commit changes** ตรวจว่า Settings → Pages เผยแพร่จาก branch `main` และ folder `/ (root)`

## ตั้งค่า SEO ก่อนส่งให้ Google
- แก้ canonical URL และ SearchAction URL ใน `<head>` ของ `index.html` จาก `https://bermongkol.github.io/` เป็น URL จริงของเว็บไซต์
- เมื่อทราบ URL จริงแล้ว สร้าง `sitemap.xml` ที่มี URL แบบเต็มของหน้าแรกและหน้า HTML ทั้ง 5 หน้า แล้วเพิ่มบรรทัด `Sitemap: https://.../sitemap.xml` ใน `robots.txt`
- เพิ่ม property ใน Google Search Console และส่ง sitemap
- ตรวจให้แน่ใจว่าทุกหน้ามีเนื้อหาที่ไม่ซ้ำกันและลิงก์ภายในทำงานได้
- เปลี่ยน `hello@example.com` เป็นอีเมลจริง และจัดทำนโยบายความเป็นส่วนตัว/หน้าเกี่ยวกับเราให้ตรงกับการใช้งานจริง

## ข้อควรรู้
เนื้อหาเลขศาสตร์เป็นความเชื่อส่วนบุคคลเพื่อการศึกษาและความบันเทิง ไม่ใช่คำทำนายทางวิทยาศาสตร์ เครื่องมือเป็นเดโมและไม่รับประกันผลลัพธ์ การทำ SEO ไม่รับประกันอันดับการค้นหา
